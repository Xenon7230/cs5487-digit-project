# 项目汇报：代码内容、真实结果与完成度评估

> 简短内部汇报（非课程提交物）。全部数字来自 `outputs/` 中的真实运行产物。

## 1. 代码做了什么

单一 CLI（`python -m digit_project.run`）从四个 TXT 数据文件出发，完成读取、校验、建模、调参、测试与出图：

| 模块 | 职责 |
|---|---|
| `data.py` | TXT（可选 `.mat`）读取；MATLAB 1-based→0-based 索引；形状/像素范围/标签/切分不交叠/全库覆盖/类均衡的严格校验 |
| `models.py` | 5 个锁定配置；PCA + 分类器的 sklearn `Pipeline`；固定 `StratifiedKFold(3, shuffle, seed=42)` 的 `GridSearchCV` |
| `experiments.py` | Experiment A（5 模型 × 2 trials）、B（PCA 4 档 × LR/RBF × 2 trials）、C（RBF 混淆矩阵与错误对） |
| `plots.py` | 8 张 300dpi PNG（模型对比、PCA 精度/耗时、CV 热力图、2 混淆矩阵、2 错例图） |
| `run.py` | CLI、日志、5 个 CSV、`run_metadata.json`（版本/种子/数据 SHA-256）、自动实验笔记 |

测试：`tests/` 共 **22 个 pytest**，覆盖读取方向、索引转换、切分协议、PCA 泄漏守卫（指纹级验证）、小型 smoke、空错例绘图、热力图回归、真实数据 baseline 回归。

## 2. 实际运行设置

- 环境：Python 3.11.18，scikit-learn 1.9.1，numpy 2.4.6，pandas 3.1.1，matplotlib 3.11.2
- 种子 42，`n_jobs=1`，完整运行 **196 s**（空闲机器；繁忙时约 400 s）
- 数据：真实 `digits4000`，两轮各 2000/2000，writer 隔离的官方划分
- 运行日志无 warning / error；pytest 22/22 通过

## 5. 结果指标合理性评估

用"预估 vs 实测"和内部一致性两组证据判断数字是否可信：

1. **Baseline 零误差复现**：两轮与老师结果完全一致，证明读取方向、索引、标签对齐、距离度量全部正确——这是后续所有数字可信的前提。
2. **与 proposal 预估的对照**：
   - RBF SVM ≈ 93.65%，落在预估的"low-to-mid 90s"区间；
   - PCA 50–100 维保持精度（±0.25 个百分点）且训练耗时降至约 1/3，符合"保留大部分精度、数倍提速"的预估；
   - LDA 低于判别式方法，符合"高斯类条件假设受限"的预判；
   - 唯一超出预估的是 1-NN 高于 Linear SVM/LR/LDA——原始像素上局部近邻结构强，这在 2000 训练样本规模下合理，不属于异常。
3. **LDA 异常低分的独立复核**：换 `eigen` solver + shrinkage 得到完全相同结果（86.75% / 86.30%），而不加 shrinkage 的 `svd` 只有 78.4%/78.0%——说明 86.5% 是真实的模型局限，不是实现错误。
4. **内部一致性**：Macro-F1 与 Accuracy 差距 ≤0.003（类别均衡、无单类塌陷）；测试精度与 CV 精度差距在 ±0.4 个百分点内（无调参泄漏导致的虚高）。
5. **量级合理性**：2000 训练样本、784 原始像素、10 类——1-NN 约 91–92%、核 SVM 约 93–94% 与这类数据的常见经验一致。

结论：**全部结果指标可信、自洽，且与 proposal 的预估方向一致**；没有好得可疑的数字，也没有实现层面的异常。
